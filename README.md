# Révision BHT — Chef de groupe 🎖️

App PWA de révision complète pour le BHT (BMPM) :

- 🎤 **Oral** — 21 thèmes, script complet 10 minutes (accroche, problématique, parties, conclusion, question jury)
- ✅ **Quiz** — 73 questions corrigées immédiatement (par thème, marathon, « mes erreurs »)
- ✍️ **DTP** — épreuve écrite 2 h : trame 4 rubriques, timing, 10 réflexes, glossaire, exemple corrigé
- ⏱️ **Chrono** — oral 10 min et DTP 2 h jalonnés (vibreur), pause/reprise, tirage de sujet
- ⭐ **CDG** — rôle du chef de groupe, chiffres clés, calage de l'oral

Avancement sauvegardé sur l'appareil (localStorage). Fonctionne hors ligne (installable sur l'écran d'accueil).

**Utiliser l'app :** https://jeffbuzz060684.github.io/revision-bht/

_Déploiement : GitHub Pages via GitHub Actions, icônes PNG générées à chaque déploiement (node tools/gen-icons.js)._
